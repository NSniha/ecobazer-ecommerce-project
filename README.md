## Overview

**Ecobazar** is a complete front-end eCommerce website built to deliver a smooth, efficient online grocery shopping experience. The project focuses on clean UI/UX, intuitive navigation, a modular structure, and a fully mobile-friendly interface — demonstrating how a real-world online shopping platform can be built using only front-end technologies while keeping production-quality standards.

The site includes all essential eCommerce pages — product listing, product details, categories, wishlist, cart, and checkout — alongside supporting content pages like About, Blog, and Contact for a complete commercial structure.

> This project was built as a final-year submission for a Bachelor of Science in Computer Science and Engineering (CSE), applying practical front-end development skills, reusable component design, and a production-ready interface suitable for real deployment or future backend integration.

---

## Key Features

- Product listing and product details pages
- Shopping cart with live item count and subtotal
- Wishlist system
- Category browsing
- Search and filter functionality
- Multi-step checkout page
- Sign In / Sign Up pages
- Blog listing and blog details pages
- About and Contact pages
- FAQ page
- Custom 404 error page
- Fully responsive design across desktop, tablet, and mobile
- SEO-ready metadata, Open Graph, and Twitter Card tags

## Getting Started (Run Locally)

No build tools or installation steps are required — this is a static site.

**1. Clone the repository**
```bash
git clone https://github.com/NSniha/ecobazer-ecommerce-project.git
```

**2. Navigate into the project folder**
```bash
cd ecobazer-ecommerce-project
```

**3. Open the project**

Open `index.html` directly in your browser, **or** serve it locally for the best experience (recommended, since some browsers restrict local file access):

```bash
# Using VS Code
# Install the "Live Server" extension, then right-click index.html → "Open with Live Server"

# Or using Python
python -m http.server 5500
```

Then visit `http://localhost:5500` in your browser.
